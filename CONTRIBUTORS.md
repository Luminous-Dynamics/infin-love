## How to Be Recognized

### Automatic Recognition

When you contribute via Pull Request:
1. Your GitHub username added to this file
2. Contribution type noted
3. Link to your profile
4. Thank you in release notes

### Manual Recognition

For other contributions (bug reports, discussions, financial support):
1. We'll add you with your permission
2. Let us know how you'd like to be recognized
3. Tell us your preferred link (GitHub, website, etc.)

### Recognition Levels

**All contributors are equal**, but we note:

| Level | Criteria |
|-------|----------|
| **Contributor** | Any accepted contribution |
| **Regular Contributor** | 3+ accepted contributions |
| **Core Contributor** | 10+ accepted contributions + ongoing involvement |
| **Maintainer** | Trusted with merge/deploy permissions |

**Note**: These are descriptive, not hierarchical. A single excellent contribution can impact more than many small ones.

## Contribution Recognition Philosophy

### Why We Recognize Contributors

1. **Gratitude** - Honoring the gift economy
2. **Transparency** - Clear who builds this
3. **Inspiration** - Others see contribution is welcomed
4. **Community** - Building relationships, not just code
5. **Accountability** - We're responsible to contributors

### What We Don't Do

❌ **No contributor rankings** - No "top contributors" list
❌ **No commit counting** - Quality over quantity
❌ **No shame or pressure** - Contribute when inspired, not guilted
❌ **No private recognition only** - Public gratitude is important

### Sacred Reciprocity in Recognition

In gift economy:
- **Gifts create relationships**, not debts
- **Receiving with gratitude** completes the circle
- **Recognition is not payment** - it's acknowledgment
- **Future contributions are always welcome**, never obligated

**Your past contribution doesn't create an expectation of future contributions.**

You're free. You're honored. You're welcomed back anytime.

## Recognition Template

When we add contributors, we use this format:

- Contributions: [type] [brief description]
- Joined: [month year]
