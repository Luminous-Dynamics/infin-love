## Accessibility

### Essential Guides

**Getting Started**
- [WebAIM Introduction](https://webaim.org/intro/) - Accessibility basics
- [The A11Y Project](https://www.a11yproject.com/) - Community-driven a11y resources
- [web.dev Accessibility](https://web.dev/learn/accessibility/) - Complete course

**WCAG Standards**
- [WCAG 2.1 Quick Reference](https://www.w3.org/WAI/WCAG21/quickref/) - Interactive checklist
- [How to Meet WCAG](https://www.w3.org/WAI/WCAG21/quickref/) - Techniques and understanding
- [WebAIM WCAG 2 Checklist](https://webaim.org/standards/wcag/checklist) - Practical checklist

### Testing Tools

**Automated Testing**
- [WAVE](https://wave.webaim.org/) - Browser extension
- [axe DevTools](https://www.deque.com/axe/devtools/) - Browser extension
- [Lighthouse](https://developer.chrome.com/docs/lighthouse/) - Built into Chrome
- [Pa11y](https://pa11y.org/) - Command-line tool

**Screen Readers**
- [NVDA](https://www.nvaccess.org/) - Free (Windows)
- [JAWS](https://www.freedomscientific.com/products/software/jaws/) - Industry standard (Windows)
- [VoiceOver](https://www.apple.com/accessibility/voiceover/) - Built-in (Mac/iOS)
- [WebAIM Screen Reader Guide](https://webaim.org/articles/screenreader_testing/) - Testing guide

### Specific Topics

**Color & Contrast**
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)
- [Accessible Colors](https://accessible-colors.com/) - Color palette tool

**ARIA**
- [ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/) - Patterns and widgets
- [Using ARIA](https://www.w3.org/TR/using-aria/) - W3C guide

**Keyboard Navigation**
- [WebAIM Keyboard](https://webaim.org/articles/keyboard/) - Keyboard accessibility

### Learning Resources

**Courses**
- [Udacity Web Accessibility](https://www.udacity.com/course/web-accessibility--ud891) - Free course
- [Deque University](https://dequeuniversity.com/) - Paid, comprehensive

**Books**

## How to Use These Resources

### For Complete Beginners

Start here:
1. [GitHub Skills](https://skills.github.com/) - Learn Git/GitHub
2. [freeCodeCamp](https://www.freecodecamp.org/) - Learn web development
3. [The A11Y Project](https://www.a11yproject.com/) - Learn accessibility
4. [First Contributions](https://github.com/firstcontributions/first-contributions) - Make first open source contribution

### For Web Developers

Level up:
1. [MDN Web Docs](https://developer.mozilla.org/) - Deep technical reference
2. [web.dev Learn](https://web.dev/learn/) - Modern best practices
3. [WCAG Quick Reference](https://www.w3.org/WAI/WCAG21/quickref/) - Accessibility standards
4. [Open Source Guides](https://opensource.guide/) - Contributing effectively

### For Designers

Essential resources:
1. [Laws of UX](https://lawsofux.com/) - UX principles

## Contributing to This List

Found a great resource? Help others discover it!

**How to suggest additions:**
1. Open an issue with the resource link and why it's valuable
2. Submit a PR adding it to the appropriate section
3. Discuss in [GitHub Discussions](https://github.com/Luminous-Dynamics/infin-love/discussions)

**Guidelines for resources:**
- Free or have significant free tier
- High quality and well-maintained
- Accessible and beginner-friendly when possible
- Aligned with our values (open, inclusive, educational)
