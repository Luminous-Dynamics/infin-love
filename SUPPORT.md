## Ways to Get Help

### 1. Check Existing Resources

Before asking for help, please check:

- **[README](README.md)** - Project overview, features, and setup
- **[CONTRIBUTING](CONTRIBUTING.md)** - Contribution guidelines and development tips
- **[TESTING](TESTING.md)** - Testing procedures and troubleshooting
- **[FAQ Section](#frequently-asked-questions)** - Common questions answered below
- **[GitHub Issues](https://github.com/Luminous-Dynamics/infin-love/issues)** - Search existing issues

### 2. GitHub Discussions (Recommended)

For general questions, ideas, and community interaction:

**Visit**: [GitHub Discussions](https://github.com/Luminous-Dynamics/infin-love/discussions)

**Good for**:
- General questions about the project
- Feature ideas and brainstorming
- Showing off your contributions
- Community connection and conversation
- Philosophy and sacred reciprocity discussions

### 3. Open an Issue

For specific bugs, feature requests, or questions:

**Visit**: [Create New Issue](https://github.com/Luminous-Dynamics/infin-love/issues/new/choose)

**Issue Types**:
- 🐛 **Bug Report** - Something isn't working
- ✨ **Feature Request** - Suggest an enhancement
- ❓ **Question** - Ask for help or clarification

**Please include**:
- Clear description of your question/issue
- Steps to reproduce (for bugs)
- Browser and device information
- Screenshots if applicable
- What you've already tried

### 4. Email Contact

For private matters, security issues, or personal support:

**Email**: tristan.stoltz@gmail.com

**Good for**:
- Security vulnerabilities (see [SECURITY.md](SECURITY.md))
- Private concerns
- Partnership inquiries
- Media requests
- Anything requiring confidentiality

**Expected response time**: Within 48 hours (usually faster)

### 5. Community Support

Help each other in the spirit of sacred reciprocity:

- Answer questions in GitHub Discussions
- Comment on issues with helpful insights
- Share your experiences and solutions
- Offer encouragement and support

### Technical Questions

<details>
<summary><strong>How do I report a bug?</strong></summary>

1. Check if the bug is already reported in [Issues](https://github.com/Luminous-Dynamics/infin-love/issues)
2. If not, create a new [Bug Report](https://github.com/Luminous-Dynamics/infin-love/issues/new?template=bug_report.yml)
3. Include all requested information
4. Be patient - we'll respond as soon as we can

See [CONTRIBUTING.md](CONTRIBUTING.md#pull-request-process) for more details.
</details>

<details>
<summary><strong>How do I set up the project locally?</strong></summary>

```bash
# Clone the repository
git clone https://github.com/Luminous-Dynamics/infin-love.git
cd infin-love

# Serve locally
python -m http.server 8000
# or
npx serve

# Visit http://localhost:8000
```

See [README.md](README.md#local-development) for more details.
</details>

<details>
<summary><strong>How do I test accessibility?</strong></summary>

We have a comprehensive testing guide! See [TESTING.md](TESTING.md#accessibility-testing) for:
- Keyboard navigation testing
- Screen reader testing
- Color contrast checking
- Automated accessibility scans

</details>

<details>
<summary><strong>Why isn't the site working on my browser?</strong></summary>

Infin.Love supports modern browsers:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

If you're experiencing issues:
1. Clear your browser cache
2. Disable browser extensions temporarily
3. Check the browser console for errors (F12)
4. Report the issue with browser/version details

</details>

### Form & Features

<details>
<summary><strong>How does the email signup form work?</strong></summary>

The form uses [Formspree](https://formspree.io) to collect email addresses. When you submit:
1. Your information is sent to Formspree
2. The site maintainer receives an email notification
3. You should see a success message

If you don't see a success message, check your email format and try again.
</details>

<details>
<summary><strong>Can I install Infin.Love as an app?</strong></summary>

Yes! Infin.Love is a Progressive Web App (PWA):
- **On mobile**: Look for "Add to Home Screen" in your browser menu
- **On desktop**: Look for the install icon in your browser's address bar

This gives you an app-like experience without downloading from an app store.
</details>

### Philosophy & Values

<details>
<summary><strong>What is sacred reciprocity?</strong></summary>

Sacred reciprocity is the practice of giving and receiving as a unified flow, rather than as transactions. It's based on:
- Trust rather than control
- Generosity rather than accumulation
- Relationships rather than transactions
- Abundance rather than scarcity

Learn more at [evolvingresonantcocreationism.com](https://evolvingresonantcocreationism.com)
</details>

<details>
<summary><strong>What are Gift Circles?</strong></summary>

Gift Circles are communities where members share gifts freely:
- **Wisdom Circle** - Knowledge and mentorship
- **Creativity Circle** - Art, music, writing
- **Healing Circle** - Emotional support
- **Service Circle** - Skills and time
- **Abundance Circle** - Resources and opportunities
- **Sacred Tech Circle** - Consciousness-first technology

Visit [infin.love](https://infin.love) to learn more and join.
</details>
